# TP2 : deux machines virtuelles en réseau avec VirtualBox

Cours : Introduction au Cloud, L3 SI (BDGL)

**Auteurs :** TRA BI TRA Christian David et Kouadio Yao Boffouo Siedou

## Contenu du dépôt
- [`TP2.md`](TP2.md) : compte rendu du TP (introduction, termes importants, commandes, sorties, captures, réponses aux questions, difficultés, conclusion)
- `images/` : captures d'écran utilisées dans le compte rendu
- `TP2_Presentation.pptx` : présentation du TP

## Résumé
Clonage de l'image `ubuntu-srv` en deux VM (`web` et `client`), création d'un réseau privé `tp-cloud` (10.10.0.0/24), test de connectivité, installation de Nginx sur `web`, pare-feu `ufw` (port 80 fermé puis ouvert), mesure des ressources consommées et nettoyage.
